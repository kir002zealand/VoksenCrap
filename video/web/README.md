# Webkopier
Komprimerede kopier af de tre brugerleverede originalfiler i mappen ovenover:
- opvasker.mp4: Lil peanut 1.1.mp4
- reklame.mp4: mike jønson 1.1.mp4
- fraklip.mp4: fraklip 1.2.mp4

H.264, maksimalt 1280 px, CRF 24, AAC 128 kbit/s og MP4 faststart. Ingen beskæring. Originalerne bevares til redigering; publicér webkopierne frem for masterfilerne. Afprøv lyd og visuel kvalitet i en browser før lancering. Ingen undertekster er tilføjet eller fjernet.
